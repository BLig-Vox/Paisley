# Downloads sheet

The user corrected the initial floating overlay: Downloads must be a sheet, not
a floating card. Use a full-width page in the browser's GTK Stack, flush with
the content area and with no scrim, rounded border or shadow. Align file rows
under File, Size, Status, Date and Actions headings. The toolbar stays available.
Escape, Close or the Downloads toolbar toggle returns to the prior browser page.
Keep bundled file-type icons, readable dates and all existing transfer, reveal,
clear and persistence semantics. No file contents are inspected for icon selection.
