# Daily browser and interactive automation implementation plan

> **For agentic workers:** Follow the scoped task contracts below, write failing tests first, implement, then verify. Do not commit or publish without the user's request.

**Goal:** Implement Browny's roadmap, including interactive visual automation that clicks, types arbitrary text, scrolls, and navigates—not a read-only substitute.

**Architecture:** Keep Rust/GTK4/WebKitGTK. Isolate persistent profiles in distinct runtimes; keep private/test profiles ephemeral. Prefer native engine APIs for Inspector, downloads, blocking, capture and real input. A provider-neutral MCP adapter must not expose host-shell or arbitrary personal-profile control.

**Tech stack:** Existing GTK4/WebKitGTK/url, serde/serde_json for bounded versioned storage/protocol data. Interactive fixture adapter embeds Python standard-library code through Rust; installed bubblewrap/dbus-run-session isolate native WebKitWebDriver after explicit approval and capability verification.

**Spec:** `../../../ROADMAP.md` (interactive automation correction dated 2026-11-07).

## Global constraints

- Rust 1.92+, GTK 4.10+, WebKitGTK 6.0 API; never disable TLS/sandbox defaults.
- No system package installs, commits, pushes, external publication, or engine replacement without consent.
- Test using temporary local fixtures and disposable profiles; don't modify the user's normal browser data.
- Normal profiles persist; private profiles never write restore/history records.
- Automation is opt-in, interactive, visible, and revocable. Never label DOM-script clicks as native input.
- State unimplemented or unverified requirements honestly; roadmap completion requires evidence.

## Review focus

- Profile locks, corrupted/future-version state, path traversal and symlink paths must fail without destroying existing state.
- Download names and destination collisions must not overwrite user files or execute content.
- Background/reordered tabs and lazy session restoration must not corrupt active-tab state or user address drafts.
- Owned-engine memory accounting must distinguish partial metrics from full application coverage.
- Automation must not silently reach personal profiles, retain control after Stop, or misrepresent synthetic input/capture readiness.
